# 📊 Risk Assessment (CIS RAM)

[View the published project page](https://hubexia.github.io/osen_grc_portfolio/03_risk_assessment/) · [Return to the portfolio overview](../README.md)

This project demonstrates a business-focused risk method that converts risk scenarios into consistent ratings, treatment decisions, and accountable follow-up.

## Project overview

| Area | Details |
| --- | --- |
| Objective | Conduct a structured cybersecurity risk assessment covering asset identification, threat analysis, vulnerability review, scoring, and treatment planning. |
| Frameworks referenced | CIS RAM, NIST CSF risk concepts |
| Skills demonstrated | Asset inventory, threat modeling, risk scoring, risk register development, treatment planning, risk communication |
| Evidence package | 2 public-safe portfolio artifacts |

## Project workflow

1. Identified critical data, systems, and business processes.
2. Documented relevant threat events and control weaknesses.
3. Scored likelihood and impact using a consistent rubric.
4. Recorded risks with owners and target dates.
5. Selected mitigation, transfer, acceptance, or avoidance treatments.
