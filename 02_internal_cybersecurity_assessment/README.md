# 🔎 Internal Cybersecurity Assessment

[View the published project page](https://hubexia.github.io/osen_grc_portfolio/02_internal_cybersecurity_assessment/) · [Return to the portfolio overview](../README.md)

This project demonstrates how security evidence and control expectations are translated into clear findings, business impact, ownership, and actionable remediation.

## Project overview

| Area | Details |
| --- | --- |
| Objective | Conduct a comprehensive cybersecurity assessment using ISO/IEC 27001, CIS Controls v8.1, and NIST CSF 2.0, then communicate security gaps and recommendations. |
| Frameworks referenced | ISO/IEC 27001, CIS Controls v8.1, NIST CSF 2.0 |
| Skills demonstrated | Audit scoping, evidence collection, control testing, risk ranking, remediation planning, executive reporting |
| Evidence package | 3 public-safe portfolio artifacts |

## Project workflow

1. Defined systems, business processes, and assessment boundaries.
2. Cross-mapped frameworks to reduce duplicate testing.
3. Reviewed policies, procedures, configurations, diagrams, and vulnerability evidence.
4. Tested control design and operating effectiveness.
5. Ranked findings and prepared an executive summary with technical detail.
