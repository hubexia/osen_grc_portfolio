🧭 Framework Review & Mapping

This project demonstrates how overlapping security frameworks can be normalized into a practical control view without losing framework-specific intent.

Objective: Compare major cybersecurity frameworks and recommend adoption strategies that fit governance, risk, and assurance needs.

Project Workflow

  1. Reviewed the purpose, structure, and intended use of each framework.
  2. Identified common control themes and unique requirements.
  3. Built a crosswalk for governance, protection, detection, response, and recovery.
  4. Documented gaps and sources of duplicate effort.
  5. Prepared adoption recommendations based on organizational needs.
