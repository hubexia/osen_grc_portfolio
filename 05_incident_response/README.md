# 🚨 Incident Response Program

[View the published project page](https://hubexia.github.io/osen_grc_portfolio/05_incident_response/) · [Return to the portfolio overview](../README.md)

This project demonstrates how roles, escalation, communications, scenario playbooks, and after-action improvement fit together in a practical response program.

## Project overview

| Area | Details |
| --- | --- |
| Objective | Develop an incident response capability and validate its workflow through a tabletop exercise. |
| Frameworks referenced | NIST incident response lifecycle, organizational crisis-management practices |
| Skills demonstrated | Incident planning, playbook development, tabletop facilitation, crisis coordination, documentation, lessons learned |
| Evidence package | 4 public-safe portfolio artifacts |

## Project workflow

1. Defined response roles, severity levels, notification paths, and evidence handling.
2. Created phishing, ransomware, and insider-threat playbooks.
3. Designed and facilitated a scenario-based tabletop exercise.
4. Captured decisions, gaps, and communication issues.
5. Converted lessons learned into assigned improvement actions.
