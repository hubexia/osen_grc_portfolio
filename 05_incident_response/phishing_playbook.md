# Phishing Response Playbook

1. Capture the message, headers, URLs, attachments, recipient list, and user actions.
2. Determine whether credentials were entered, malware executed, or sensitive data disclosed.
3. Block sender infrastructure, URLs, domains, and file indicators where appropriate.
4. Remove matching messages from mailboxes and isolate affected endpoints.
5. Reset compromised credentials, revoke sessions, and review authentication logs.
6. Notify affected users and required stakeholders.
7. Document scope, containment, root cause, and awareness follow-up.
