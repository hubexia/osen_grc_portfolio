# 🎓 Cybersecurity Awareness Training

[View the published project page](https://hubexia.github.io/osen_grc_portfolio/06_security_awareness/) · [Return to the portfolio overview](../README.md)

This project demonstrates how common security risks can be translated into clear training, measurable learning objectives, and practical user actions.

## Project overview

| Area | Details |
| --- | --- |
| Objective | Improve organizational security awareness through structured training materials, facilitated sessions, and learning evaluation. |
| Frameworks referenced | Security-awareness good practices, organizational policy requirements |
| Skills demonstrated | Needs assessment, training design, facilitation, public speaking, quiz design, outcome evaluation |
| Evidence package | 3 public-safe portfolio artifacts |

## Project workflow

1. Assessed audience needs and common human-risk scenarios.
2. Defined measurable learning objectives.
3. Developed presentations, posters, and knowledge checks.
4. Planned delivery for new hires and recurring annual training.
5. Evaluated results and identified reinforcement topics.
