# Security Awareness Knowledge Check

1. You receive an unexpected MFA prompt. What should you do?
   - A. Approve it to stop the prompts
   - B. Deny it and report the event
   - C. Ignore it permanently

2. A supplier asks you to send customer data to a new personal email address. What is the best response?
   - A. Send it if the request sounds urgent
   - B. Verify through an approved channel and use authorized transfer methods
   - C. Compress the data first

3. You believe you clicked a phishing link. What should you do first?
   - A. Wait to see whether anything happens
   - B. Delete browser history
   - C. Report it immediately and follow response instructions

## Answer key

1. B
2. B
3. C
