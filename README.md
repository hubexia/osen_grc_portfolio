# Osen Osagie — GRC Portfolio

**Governance, Risk & Compliance Cybersecurity Professional**

Welcome to my Governance, Risk, and Compliance (GRC) portfolio.<br>
This repository showcases applied policy development, internal assessment, risk management, third-party oversight, incident readiness, security awareness, vulnerability remediation, framework mapping, and business continuity work.

The projects are aligned with **ISO/IEC 27001**, **CIS Controls v8.1**, **NIST Cybersecurity Framework 2.0**, **CIS RAM**, and selected **HIPAA** and **PCI DSS** requirements.

---

## Overview

Each folder represents a distinct GRC project, assessment, policy set, or supporting evidence package used to demonstrate practical cybersecurity governance and risk-management skills.

| Section | Description |
| --- | --- |
| [Cybersecurity Governance](https://github.com/hubexia/osen_grc_portfolio/tree/main/01_cybersecurity_governance) | Policy development and review covering inventory, gap analysis, drafting, peer review, and delivery aligned with ISO/IEC 27001, CIS Controls v8.1, NIST CSF 2.0, HIPAA, and PCI DSS. |
| [Internal Cybersecurity Assessment](https://github.com/hubexia/osen_grc_portfolio/tree/main/02_internal_cybersecurity_assessment) | An audit-style assessment covering scoping, framework mapping, evidence review, control testing, gap identification, risk ranking, and remediation planning. |
| [Risk Assessment (CIS RAM)](https://github.com/hubexia/osen_grc_portfolio/tree/main/03_risk_assessment) | A structured assessment of assets, threats, vulnerabilities, likelihood, impact, and treatment options using CIS RAM. |
| [Third-Party Risk Assessment](https://github.com/hubexia/osen_grc_portfolio/tree/main/04_third_party_risk) | Vendor due diligence covering questionnaire design, documentation review, risk scoring, contractual controls, remediation requests, and ongoing monitoring. |
| [Incident Response Program](https://github.com/hubexia/osen_grc_portfolio/tree/main/05_incident_response) | An incident response capability with policy, phishing, ransomware, and insider-threat playbooks, tabletop facilitation, and lessons learned. |
| [Cybersecurity Awareness Training](https://github.com/hubexia/osen_grc_portfolio/tree/main/06_security_awareness) | A human-centered awareness program built from needs assessment, presentations, posters, quizzes, delivery planning, and learning evaluation. |
| [Vulnerability Assessment & Remediation](https://github.com/hubexia/osen_grc_portfolio/tree/main/07_vulnerability_assessment) | A remediation-governance workflow for reviewing penetration-test findings, categorizing severity, assigning action, and tracking closure. |
| [Framework Review & Mapping](https://github.com/hubexia/osen_grc_portfolio/tree/main/08_framework_mapping) | A comparative review of ISO/IEC 27001, CIS Controls v8.1, and NIST CSF 2.0 with a cross-mapped control matrix and adoption recommendations. |
| [Business Continuity & Disaster Recovery](https://github.com/hubexia/osen_grc_portfolio/tree/main/09_business_continuity) | Business impact analysis, recovery priorities, RTO/RPO targets, backup and alternate-site strategies, and testing recommendations. |
