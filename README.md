# Osen Osagie — GRC Portfolio

Public Governance, Risk, and Compliance portfolio for Osen Osagie, maintained by Hubexia and published through GitHub Pages.

## Live site

`https://hubexia.github.io/osen_grc_portfolio/`

## Portfolio areas

1. Cybersecurity Governance — Policy Development & Review
2. Internal Cybersecurity Assessment / Audit
3. Risk Assessment using CIS RAM
4. Third-Party Risk Assessment
5. Incident Response Program & Tabletop Exercise
6. Cybersecurity Awareness Training
7. Vulnerability Assessment & Remediation Strategy
8. Framework Review & Mapping
9. Business Continuity & Disaster Recovery

Each project directory contains a public project page plus sample artifacts that demonstrate the project method and deliverables without exposing confidential client data.

## Local development

Regenerate the HTML pages:

```bash
npm run build
```

Preview locally:

```bash
npm run preview
```

Then open `http://localhost:4173/`.

## Deployment

The workflow in `.github/workflows/deploy-pages.yml` publishes the repository as a static GitHub Pages site after every push to `main`.

Repository: `https://github.com/hubexia/osen_grc_portfolio`

## Design reference

The visual system intentionally mirrors the Cayman-style GitHub Pages reference supplied for this project: blue-to-green hero, white content canvas, green headings, blue links, Open Sans typography, and the same desktop/mobile spacing behavior.
